# Carpeta de imágenes

Agrega aquí las fotos reales del salón (por ejemplo, descargadas desde tu
Facebook o Instagram) y reemplaza los bloques `.gallery-item` en `index.html`
por etiquetas `<img>`, por ejemplo:

```html
<div class="gallery-item">
  <img src="images/trabajo-1.jpg" alt="Corte de cabello en Class Peluquería">
</div>
```

Recomendaciones:
- Usa fotos cuadradas (1:1) de al menos 800x800px para la galería.
- Comprime las imágenes (por ejemplo con [squoosh.app](https://squoosh.app)) antes de subirlas para que el sitio cargue rápido.
